# C. elegans Gastrulation Mechanics

This repository contains computational and data analysis code associated with our research on the mechanics of *Caenorhabditis elegans* gastrulation.

## Contents

- [hmr1_intensity_analysis](hmr1_intensity_analysis/) — Statistical analysis of HMR-1/E-cadherin fluorescence intensity at cell–cell boundaries.
- [cortical_recoil_analysis](cortical_recoil_analysis) - Quantitative analysis of cortical recoil following laser ablation.
  - Includes Python scripts for:
    - Particle tracking analysis.
    - Calculation of mean cortical recoil vectors.
    - Analysis of recoil direction relative to the anterior–posterior (AP) axis.

Additional simulation code will be added to this repository.
