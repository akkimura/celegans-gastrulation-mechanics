# C. elegans Gastrulation Mechanics

This repository contains computational and data analysis code associated with our research on the mechanics of *Caenorhabditis elegans* gastrulation.

## Contents

- [hmr1_intensity_analysis](hmr1_intensity_analysis/) — Statistical analysis of HMR-1/E-cadherin fluorescence intensity at cell–cell boundaries.

Additional simulation and analysis code will be added to this repository.
