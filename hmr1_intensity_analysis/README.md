# HMR-1 Intensity Analysis

This directory contains Python code for statistical analysis of HMR-1/E-cadherin fluorescence intensity at lateral cell–cell interfaces during *C. elegans* gastrulation (Figure 3B).

## Files

- `count_hmr1_games.py` — Performs pairwise comparisons of HMR-1 fluorescence intensity and calculates one-sided exact permutation test P-values.

## Requirements

- Python 3
- No additional Python packages are required.

## Input data

The script reads a CSV file containing HMR-1 fluorescence intensity measurements from five embryos. Each row represents one embryo, and each intensity value represents the mean fluorescence intensity at the corresponding cell–cell interface, averaged over the period of Ea/Ep internalization.

The CSV file must contain the following columns:

- `embryo` — Embryo identifier
- `Ea_MSap`, `Ea_MSpa`, `Ea_MSpp` — Ea–MS interfaces
- `Ea_ABplpa`, `Ea_ABplpp` — Ea–AB interfaces
- `Ep_P4` — Ep–P4 interface
- `Ep_AB1`, `Ep_AB2` — Two Ep–AB-associated interfaces

The path to the input CSV file is specified by `INPUT_CSV` near the beginning of the script and must be updated before execution.

## Usage

Run the script using:

```bash
python3 count_hmr1_games.py
```

The script prints the results of pairwise comparisons for individual embryos, the combined results across five embryos, and the corresponding one-sided exact permutation test P-values.

## Statistical analysis

Two comparisons are performed:

1. **Ea–MS versus Ea–AB interfaces:** The fluorescence intensities of three Ea–MS interfaces are compared pairwise with those of two Ea–AB interfaces, yielding six comparisons per embryo.

2. **Ep–P4 versus Ep–AB interfaces:** The Ep–P4 intensity is compared with those of two other interfaces, yielding two comparisons per embryo.

For each comparison, a higher intensity at the target interface is counted as a win, a lower intensity as a loss, and equal intensities as a tie. Ties contribute 0.5 to the test statistic.

Statistical significance is evaluated using one-sided exact permutation tests. The null distributions are generated by exhaustively permuting interface labels within each embryo, preserving the number of interfaces assigned to each group.

P-values are calculated as the proportion of permutations yielding a test statistic greater than or equal to the observed value. Statistical significance is assessed at P < 0.05.
